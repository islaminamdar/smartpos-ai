Download Android APK

Android 8.0 or newer. Internet is required for sales. Offline selling is a future update.

Start the first shift

  1. Sign in. Use your manager or cashier account. Keep the password private.
  2. Register this counter. Confirm the branch and give this device a clear name, such as “Front counter”. Register each device separately.
  3. Open Shift. Count the actual money in the drawer and enter that opening cash amount.
  4. Review prices, then sell. Choose items and quantities, record cash or confirmed card payment, and select Save sale. Wait for the saved receipt.
  5. Review the receipt. On the website use Print / save PDF. In the Android app, open the receipt and use the app's print control. A compatible Android print service or Save as PDF is required.
  6. Close the day. Review Reports, count the actual cash and close the shift. Investigate any difference.
If confirmation is interrupted: keep the app and its data. Use the saved-request recovery controls before making another bill for the same payment. Do not uninstall, clear storage or repeat the payment while its outcome is uncertain.

Android installation

Download the APK on the POS device, open the downloaded file and allow installation from that browser if Android asks. Complete installation, then open Internext Counter. You can turn that installation permission off afterward.

The app records card payments; it does not charge a bank card. Receipt printing depends on your device's installed print service. Direct USB/Bluetooth thermal-printer adapters and offline billing remain in development.
